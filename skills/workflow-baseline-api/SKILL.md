# Implement baseline API automation before a service change

Inspect the existing API automation repository and its instructions. Implement relevant tests for existing behavior using the approved plan and test data. Run feasible checks and record files, repository and branch/commit or diff, commands, actual results, and gaps. Do not report unrun checks as passed.

Work interactively with the engineer. Treat the handoff as context, not permission to bypass native tool approvals. Report uncertainty and preserve evidence of failures.
