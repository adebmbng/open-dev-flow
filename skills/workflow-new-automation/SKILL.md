# Implement API and UI automation for the new behavior

Use the approved plan, test data, implementation reference and baseline coverage. Add new-behavior tests only for the API or UI automation targets selected in the handoff, in their configured repositories. Do not require an unselected target or claim it was tested. Run feasible checks and record each repository, branch or PR, commands, results and gaps. Do not report unrun checks as passed.

Work interactively with the engineer. Treat the handoff as context, not permission to bypass native tool approvals. Report uncertainty and preserve evidence of failures.
