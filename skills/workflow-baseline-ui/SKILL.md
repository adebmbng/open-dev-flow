# Implement baseline UI automation and test-data preparation

Inspect the existing UI automation repository and its instructions. Automate test-data preparation and relevant existing UI behavior using approved context. Run feasible checks; record changes, commands, results, setup, cleanup and gaps. Do not report unrun checks as passed.

Work interactively with the engineer. Treat the handoff as context, not permission to bypass native tool approvals. Report uncertainty and preserve evidence of failures.
