# Contributing

Issues and pull requests are welcome. For substantial changes, please open an issue first to discuss the approach.

1. Fork the repository and create a branch from `main`.
2. Install Node.js 22.13 or later and run `npm ci`.
3. Make your changes and add or update tests where appropriate.
4. Run `npm test`, and update documentation for user-visible changes.
5. Open a pull request describing the change, why it is needed, and how you tested it.

Keep pull requests focused and do not include secrets, private logs, or local `.workflow/` data. By submitting a contribution, you agree that it is licensed under the repository's [MIT License](LICENSE).
