Setting up

Install the BFI agent skills from the ai-agents repository using its README instructions. Configure Atlassian MCP in your selected agent and sign in when prompted. Restart the agent after installing plugins.

Skill checks look for global skill files and BFI plugin cache files. A file in the cache does not prove the plugin is enabled or loaded. Project-local skills are not checked here.

Atlassian access depends on configuration, authentication and network availability. A configuration check alone does not verify all three.
